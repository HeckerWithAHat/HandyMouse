# HandyMouse

HandyMouse is an app built for my Haptic Glove, a wearable smart glove. 

## Features

- Clicking, Dragging, and Mouse moving
- Token-Based Authentication

## Getting Started

Follow these instructions to set up and run the project on your local machine.

### Prerequisites

asyncio, websockets, getpass, pyautogui, tkinter, secrets

### Installation

1. Clone the repository:

```bash
git clone https://github.com/HeckerWithAHat/HandyMouse.git
cd HandyMouse
```

2. Start the program:

```bash
python main.py
```
